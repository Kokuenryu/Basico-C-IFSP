# 🧮 Lista 01: Operações Aritméticas em C#

Este repositório contém a resolução da primeira lista de exercícios de lógica de programação, focada em operações aritméticas fundamentais. O projeto foi desenvolvido como parte dos meus estudos em **Automação Industrial** no **IFSP Cubatão**.

## 📋 Exercícios Resolvidos

[cite_start]A lista contempla 12 problemas de cálculo e lógica:
1. [cite_start]**area_retangulo**: Cálculo através da base e altura.
2. [cite_start]**area_quadrado**: A partir da aresta.
3. [cite_start]**area_quadrado_diagonal**: Cálculo alternativo usando a diagonal.
4. [cite_start]**area_triangulo**: Base versus altura.
5. [cite_start]**media_A4**: Processamento de quatro valores.
6. [cite_start]**media_G2**: Cálculo entre dois valores.
7. [cite_start]**milhas_km**: Milhas marítimas para quilômetros (1 milha = 1.852m).
8. [cite_start]**temperatura**: Celsius para Fahrenheit ($F = C \times 1.8 + 32$).
9. [cite_start]**area_circulo**: Cálculo a partir do diâmetro digitado.
10. [cite_start]**Dolares**: Dólar para Real (R$) baseado em cotação atual.
11. [cite_start]**pow**: Cálculo de $X^Y$ utilizando `Math.Pow`.
12. [cite_start]**produtos5**: Soma de 5 produtos com cálculo de troco.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** C# (.NET 10)
* **Ambiente:** Linux (configurado via Git SSH)
* **Paradigma:** Programação Estruturada
