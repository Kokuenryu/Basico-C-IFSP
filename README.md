# 🧮 Lista 01: Operações Aritméticas em C#

Este repositório contém a resolução da primeira lista de exercícios de lógica de programação, focada em operações aritméticas fundamentais. O projeto foi desenvolvido como parte dos meus estudos em **Automação Industrial** no **IFSP Cubatão**.
